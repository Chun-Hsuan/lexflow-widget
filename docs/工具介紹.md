# LexFlow 筆記：工具介紹

給接手協助修改這個工具的 AI 看。使用者是準備學測的台灣學生，一律用繁體中文溝通，不要中途換成英文。他不寫程式，改動前先用白話說明要改什麼，重要的視覺改動先做示意圖給他看再動手。

---

## 一、這是什麼

一個 Android App（使用者的手機是 Samsung Galaxy S25+），用來讓他每天自然地複習用 LexFlow 背單字時存下的英文用法筆記。

**使用者的日常流程**

1. 主畫面上有一個小工具，顯示一則筆記的**標題和摘要**。
2. 點小工具，打開**詳細頁**，讀完整的筆記。
3. 讀完**按住**右下角圓形的 **Done** 0.6 秒，跳出一句英文短句，頁面自動關閉回到主畫面，小工具已經換成下一則。
4. 想主動查某則筆記時，打開**筆記庫**搜尋或依分類瀏覽（見下面「筆記庫」）。

**另外兩份文件**
- `docs/筆記整理提示詞.md`：整理新筆記、上傳的規則。新增或修改筆記內容時看這份。
- 本文件：修改 App 本身時看這份。

## 三、目前定案的設定

### 主畫面小工具（`res/layout/widget.xml`、`res/values/colors.xml`）

- 深色實心卡片，圓角 28dp，和使用者主畫面上三星日曆小工具的風格一致。
- 底色：主體是黑色，只帶一點點深綠，預設 `#111714`（色調 150、濃淡 28、明暗 9）。底色存在手機裡（`WidgetTheme`），用 `ImageView` 的 `setColorFilter` 在執行時上色，所以改色不需要重新打包。
- 手機上調色：筆記庫左上角三條線 →「設定」，或長按 App 圖示選「設定」。設定頁會顯示目前色碼，使用者決定好後告訴 AI，AI 把 `WidgetTheme` 的預設值和 `colors.xml` 的 `widget_bg` 改成那個色碼即可。
- 標題：白色、粗體、一行，最大 29sp，太長時自動縮小到最小 18sp，再長就切成「…」。
- 摘要：淺灰 `#BCC1C8`，16sp，最多 3 行。
- 標題和摘要間距 13dp，整塊文字上下置中，四邊留白。
- 不顯示分類標籤。
- 點小工具打開詳細頁；讀滿當天上限後，點小工具改成打開筆記庫。
- 長按小工具時三星選單裡的「設定」（系統畫的，字和圖示 App 改不了，一個小工具也只能有這一個入口）接到筆記庫，並自動跳出鍵盤可以直接搜尋。技術上是 `note_widget_info.xml` 的 `android:configure` 指向 `SearchEntry`（`LibraryActivity` 的 activity-alias，名稱「搜尋」、放大鏡圖示）。取這個別名是在試三星會不會改用 App 提供的名字；如果選單還是顯示「設定」，就是三星固定的字，沒有別的辦法。

### 詳細頁

- 背景：ChronoFlow 的暖白紙色漸層（`#F9F8F5` → `#FCFAF6`）。
- Blob 背景：從使用者另一個專案 ChronoFlow 的 Cosmos 分頁搬過來（`NoteBlob.java` 有完整說明）。4 顆模糊色塊（蜜杏、藕荷、抹茶綠、霧霾藍），透明度 12–18%，慢慢飄、碰邊反彈、特定顏色互相柔和推開。為手機調整過：大小是螢幕寬的 50–60%，速度是原版的一半。
- 頂部：分類標籤 + 標題（31px），然後直接進正文。**詳細頁不顯示摘要**，摘要只在小工具上。
- 加了星號的筆記，分類膠囊裡在分類字左邊多一顆小實心星（「★ 辨析」）。沒加的不顯示任何星號。
- 正文 18px，小標用墨灰色 `#3A3F47`。
- 右下角圓形按鈕，每次打開從「墨水色組」隨機選一色：`#2E4A6B` `#1F5F5B` `#5B3A63` `#8A4B2A` `#4F5B2E` `#3A3F47`。
- 按鈕操作（兩種模式相同）：
  - **按住 0.6 秒**：外圈進度圈繞完一圈才算數，完成時手機輕震。中途放手進度圈退回，什麼都不算。（使用者試過 2 秒、1 秒、0.7 秒，都嫌長，定在 0.6 秒。）
  - **點一下**：外圈淡淡閃一下，暗示要按住。不跳任何文字。
  - **點兩下**：跳出「加入星號？」（已加的則是「移除星號？」），確認後才改。
- 兩種模式：
  - **複習模式**（從小工具打開，`DetailActivity`）：實心按鈕「Done」。在自己的 task 裡，所以關閉後回到主畫面而不是筆記庫。
  - **瀏覽模式**（從筆記庫打開，`BrowseActivity`）：外框樣式的「Close」，按住 0.6 秒回到清單，手機返回手勢也可以。**完全不碰排程、不算每日上限**，讀滿上限後也能看。
- 按住 Done 完成後：從下面 14 句隨機閃一句，然後關閉頁面。
  `Confirmed.` `Noted.` `Got it.` `Filed away.` `Saved.` `Locked in.` `One more down.` `In the bag.` `Nice.` `Sharp.` `Well done.` `Keep going.` `Onward.` `Another one for the essay.`

### 排程規則（`Store.java`）

- 小工具一次顯示一則，按 Done 才換。
- 按過 Done 的筆記隔 1、3、7、14 天回來，之後每 30 天一次。
- 一則放 24 小時沒按，自動換下一則；被換掉的排到後面，不算讀過。
- 下一則的順序：到期該複習的 → 還沒讀過的 → 最快到期的。
- **每日上限**：一天最多按幾次 Done，讀滿後小工具只顯示「That's all for today. / See you tomorrow.」，點了也打不開詳細頁，半夜 12 點解除。
  - 上限由使用者在手機的設定頁自己調（0 = 不限，最多 20），存在手機裡，改了立刻生效，不用重新打包。調低到已經讀的次數就當場鎖住；調高或改成不限就當場解鎖。
  - 打包參數 `dailyLimit`（`app/build.gradle`，預設 0）只是第一次安裝時的起始值。使用者原本設計是 5，目前預設不限，由他自己在設定頁決定。

### 筆記庫（`LibraryActivity`、`res/raw/library.html`）

- 入口：點 App 圖示、長按小工具選「設定」（會自動跳鍵盤）、讀滿上限後點小工具。
- 頁面：和詳細頁同一套暖白紙色、墨灰色。頂部左邊三條線、目前分類名稱，下面是搜尋框；清單每則顯示分類膠囊、標題、摘要兩行，有星號的在右上角顯示一顆星。
- 側邊選單（三條線）：最上面「LexFlow 筆記」（22px 粗體）加一條淡橫線，接著「全部、辨析、句型、文法、字詞」，一條淡橫線後是「星號」，最底下一條線和「設定」。全部都是純文字、沒有圖示；每項最右邊用淺灰小字顯示**總共幾則**（是總數，不是讀了幾則）。「設定」底下不加說明文字。
- 星號：單純書籤，**不影響排程**。存在手機裡（`Store` 的 `stars`），靠筆記 ID 對應，筆記改內容不會掉。
- 搜尋規則：
  - 不分大小寫。
  - 英文關鍵字從**單字開頭**比對（打 as 找得到 as if，不會中 cease、contrast；打 accompl 找得到 accomplished）。中文只要包含就算。
  - 排序先看層級：標題完全相符 → 標題開頭 → 標題包含 → 摘要包含 → 正文包含。正文命中時，結果底下多一行命中的片段，關鍵字標底色。
  - **在分類頁或星號頁打關鍵字，一樣搜全部筆記**，但同一層裡，目前這頁的筆記（或有星號的）排前面。清單上方小字寫「找到 N 則，辨析的排在同一層前面」。清空關鍵字就回到只顯示這一頁。
  - 每打一個字，清單跳回最上面。
- 手機返回手勢：側邊選單開著時先關選單，否則離開 App。

### 同步

- App 從 `https://raw.githubusercontent.com/Chun-Hsuan/lexflow-widget/main/notes.json` 下載筆記。
- 打開詳細頁、打開筆記庫時一定同步；小工具每 30 分鐘更新一次時，若距上次同步超過 6 小時也會同步。
- 筆記只改內容不改 ID，進度保留；刪掉的筆記就不會再出現。

## 四、怎麼改 App、發新版

1. 改 `app/` 底下的程式或設定。
2. 推到 `main`。`Build app` 會自動跑：先跑單元測試，再打包、簽章，發布到 Releases（版本號 `v1.0.<次數>`）。約 2 分鐘。
3. 確認成功：`gh run list -R Chun-Hsuan/lexflow-widget`，或 `gh run watch <id> --exit-status`。
4. 把下載連結給使用者（**每次都要貼出連結**，不要只說「同一個連結」）：
   `https://github.com/Chun-Hsuan/lexflow-widget/releases/latest/download/LexFlow-Widget.apk`
5. 使用者在手機下載、按「更新」覆蓋安裝，進度會保留。裝完從 App 圖示打開一次，小工具會重畫成新樣子。

**注意**：雲端環境連不到 Android 打包工具，不能在本機打包，一律靠 GitHub Actions。排程邏輯可以在本機用簡單的替身類別編譯 `Store.java` 和 `StoreTest.java` 先測。

## 五、不能亂動的地方

- **筆記的英文代號（檔名去掉編號的部分）**：就是 ID，改了進度會歸零。
- **`signing/release.jks` 和 workflow 裡的密碼**：換了簽章，手機上就無法覆蓋更新，只能刪掉重裝，進度全部消失。
- **`applicationId`（`com.lexflow.widget`）**：同上。
- **版本號**：用 GitHub 的執行次數自動遞增。如果把 `app.yml` 改名或重建，次數會從 1 重來，新版本號會比手機上的小，無法更新。
- 簽章檔放在公開 repo 裡，是為了方便打包的取捨。風險很低（要有人做假更新檔、還要使用者自己去裝）。使用者如果想更保險，可以把它移到 GitHub Secrets（`SIGNING_KEY_B64`、`KEYSTORE_PASSWORD`，workflow 已經支援），再從 repo 刪掉。

## 六、使用者已經否決過的設計（不要再提）

- 按 Done 後提示「N 天後再出現」：他覺得這是在講系統排程，不喜歡。
- 詳細頁顯示「已了解 0/28」這類進度：不需要。筆記庫清單也不要顯示已讀、未讀或幾天後到期。
- 加星號的筆記更常出現：星號只當書籤。
- 詳細頁頂部放搜尋圖示：不需要，筆記庫從 App 圖示和長按小工具進。
- 側邊選單項目前面的小圓點、三條線、齒輪、星星等圖示：不好看，都拿掉了，只留文字。
- 小工具半透明底：在照片桌布上很髒、很突兀。Android 一般 App 的小工具做不到毛玻璃模糊。
- 小工具字放很大、塞滿格子：看起來像字牆，和其他小工具格格不入。
- 筆記裡的 emoji、誇張詞、比喻口訣。

## 七、安裝和手機設定（使用者遇到問題時）

- 下載卡住：多半是 Chrome 在等確認，看下載清單或通知欄；不行就改用 Samsung Internet。
- 無法安裝：允許瀏覽器安裝未知應用程式；Play 安全防護選「仍要安裝」；三星「自動封鎖程式」要先關掉。
- 小工具不會自己換：設定 → 應用程式 → LexFlow 筆記 → 電池 → 不受限制。
- 小工具沒更新成新樣子：從 App 圖示打開一次，或長按小工具稍微拉一下大小。
