# LexFlow 筆記

Android 主畫面小工具：一次顯示一則英文筆記，讀完按「了解」就換下一則。

## 運作規則

- 小工具顯示一則筆記的類型、標題、一句話核心；點一下打開完整內容。
- 按「了解」後，這則會在 1、3、7、14 天後回來，之後每 30 天一次。
- 一則筆記放著 24 小時沒按，就自動換下一則，被換掉的排到後面。
- 下一則的順序：到期該複習的 → 還沒讀過的 → 最快到期的。

## 新增筆記

在 `notes/` 新增一個 `.md` 檔，檔名開頭用編號（例如 `29-xxx.md`）：

```
---
title: 標題
type: 辨析
core: 一句話核心，會顯示在小工具上
---

詳細內容（Markdown）
```

`type` 用：辨析、句型、文法、字詞。推上 GitHub 後，`notes.json` 會自動重建，手機上的 App 在打開時或每 6 小時會自己同步。

檔名去掉編號的部分是這則筆記的 ID，閱讀進度跟著它走，所以改檔名的編號沒關係，但不要改後面的名字。
