---
title: as if 的時態判斷
type: 文法
core: 先問真假：可能是真的用一般時態；與事實相反，同時用 were，更早用 had p.p.。
---

## 結論

判斷只要問自己兩個問題，順序固定：先問「真的還是假的」，再問「同時還是更早」。as if 子句用 had + p.p.，是因為「假裝的那件事」發生在主要子句動作之前，而且與事實相反。時間要以主句動詞為基準，不是以現在為基準。

## 問題 1：as if 後面說的內容，可能是真的嗎？

- 可能是真的（看起來、聽起來像是）→ 不用假設語氣，用一般時態。
  - It looks as if it is going to rain.（看起來好像要下雨了。真的有可能下雨。）
- 與事實相反或不太可能 → 用假設語氣，進入問題 2。
  - 題目線索：didn't go、其實不是、明明沒有。

## 問題 2：假裝的那件事，和主句動作是同時，還是更早？

- 同時 → were / V-ed
  - She often dresses as if she **were** a superstar.（她經常打扮得像巨星。）
  - 打扮和當巨星是同一個時間點。
- 更早 → had + p.p.
  - Laura talked as if she **had gone** to the concert.（她講得好像去過演唱會。）
  - 先「去演唱會」，後「講」，去在講之前，所以用 had gone。

## 記憶方法：往後退一格

- 假設語氣的規則，是把時態往後退一格：
  - 同時：退成過去式（were / V-ed）
  - 更早：退成過去完成式（had + p.p.）
- 這跟 if 假設語氣是同一套：If I were rich...（同時）、If I had studied...（更早）。

## 判斷流程

| 情況 | 用什麼 | 例句 |
|---|---|---|
| 可能是真的 | 一般時態 | He looks as if he is tired. |
| 與事實相反，同時 | were / V-ed | She spends money as if she were rich. |
| 與事實相反，更早 | had + p.p. | She talks as if she had been to Paris. |

## 最容易搞混的地方：要看「主句」，不是看「現在」

- 主句是過去式，不代表 as if 子句就要用 had + p.p.，還是要比較先後：
  - He talked as if he **knew** everything.（講的當下，好像什麼都知道，同時。）
  - He talked as if he **had known** everything.（講的時候，好像之前就什麼都知道，更早。）
- 兩句意思不同，所以要看你想表達哪一種。
- 主句過去式：She talked as if she had gone to it.（講是過去，去更早）
- 主句現在式：She talks as if she had been to Paris.（講是現在，去過是更早）
- 兩句主句時態不同，as if 子句都是 had + p.p.，因為都是「更早」。

## 再看兩組對照

- He spends money as if he **were** rich.（花錢像有錢人，同時，但他其實不富有）
- He spends money as if he **had won** the lottery.（花錢像中過樂透，中獎在先，但他其實沒中）
- Leo acted as if nothing **had happened**.（Leo 表現得好像什麼事都沒發生過，事情發生在表現之前。）
- 否定也一樣：She smiled as if she had never been hurt.（她笑得好像從沒受過傷。）

## 錯誤對照

- 錯：She talked as if she went to it.
  - went 和 talked 同時，意思變成「講的當下就在去」，和「去過」不同；學測中要選 had gone。
- 錯：She talks as if she has been to Paris.（事實相反時不用現在完成式）
- 對：She talks as if she had been to Paris.

## 自己測試（括號選一個）

1. He looks as if he (is / were / had been) sick.
2. She spends money as if she (were / had been) a millionaire. 她其實不是。
3. He reacted as if he (never saw / had never seen) the news before. 他其實看過。

答案：

1. is，因為看起來生病有可能是真的。
2. were，與事實相反，花錢和當百萬富翁同時。
3. had never seen，沒看過是更早的事，而且與事實相反。

## 翻譯與作文

- 中文對應：
  - 「好像是……一樣」（同時、事實不是）→ as if + were / V-ed
  - 「好像……過一樣」（更早、事實不是）→ as if + had + p.p.
  - 「看起來好像……」（可能是真的）→ look as if + 一般時態
- 翻譯示範：
  - 他表現得好像是這裡的老闆一樣。
    He acts as if he were the boss here.
    「好像是」同時發生，用 were。
  - 他表現得好像從沒見過我一樣。
    He acted as if he had never seen me before.
    「從沒見過」發生在「表現」之前，所以用 had never seen。
  - 她講得好像去過巴黎一樣（其實沒去過）。
    She talks as if she had been to Paris.
    主句 talks 是現在式，但「去過」更早，仍用 had been。
  - 她假裝好像從沒聽過這件事。
    She pretended as if she had never heard about it.
    「從沒聽過」比「假裝」更早，用 had never heard。
- 作文句型：
  - ___ as if ___ were ___.
    The little girl walked proudly as if she were a princess.（小女孩驕傲地走著，好像她是公主。）
  - ___ as if ___ had + p.p.
    He smiled at me as if nothing had happened.（他對我微笑，好像什麼事都沒發生過。）
  - When I met my old friend, we talked as if we had never been apart.（我遇見老朋友時，我們聊得好像從沒分開過。）
  - 描寫氣氛：The classroom was so quiet that it seemed as if everyone had left.（教室安靜得好像大家都離開了。）
- 中式英文陷阱：中文「好像」不分時間，容易全部寫成同一個時態。先判斷真假，再比較先後，就不會亂。
